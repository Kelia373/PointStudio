# src/main/policy

**职责**：策略层，也是**个人版与企业版差异的唯一落点**。

包含：能力白名单、配额与成本上限、审计事件规则、鉴权上下文（`userId` / `tenantId`）。

**为什么单独成包**：如果没有这个包，版本差异一定会散进业务代码，三个月后两版必然分裂。宁可现在空着，也不能缺位。

**个人版实现**：全放行 + 本地日志 + `tenantId = 'local'`。

**企业版实现**：白名单校验、配额熔断、审计推送、OIDC/RBAC 上下文。

**禁止**：

- 禁止 import `electron` / `react`；
- 禁止调用具体存储或网络实现（通过接口注入）。

## 现状

空壳，**优先生成接口**。依据 [ADR 0002](../../docs/adr/0002-技术栈选型与双版本架构.md)。
