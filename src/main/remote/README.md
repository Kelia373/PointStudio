# src/main/remote

**职责**：远端协议与传输。个人版用不到，但**接口必须先定**——这是企业版能否平滑接入的关键。

**内容**：`protocol`（消息与 RPC 定义，版本化）+ `transport`（in-process / HTTP / WebSocket 实现）。

**原则**：

- 协议先于实现：先定义消息语义与版本协商，再挑传输；
- 个人版走 in-process 传输，代码路径与企业版**完全一致**——差异只在下层实现；
- 协议变更必须向后兼容或显式版本升级。

**禁止**：import `electron` / `react`；在协议层写业务逻辑。

## 现状

空壳，接口优先。依据 [ADR 0002](../../docs/adr/0002-技术栈选型与双版本架构.md)。
