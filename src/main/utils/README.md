# src/main/utils

**职责**：跨领域、无状态、与业务无关的辅助函数。

## 为什么它必须没有任何依赖

`utils` 是**唯一能被所有包（包括 `core`）依赖**的东西。正因为它被所有人依赖，它就不能依赖任何人——否则立刻成环。

因此这里的铁律只有一条：**零依赖（除第三方纯函数库）**。

## 可以放

- 字符串 / 路径 / 时间的处理
- 类型守卫、转换器
- 纯计算（分块、哈希、序列化）
- 常量表（真正全局的那些：单位、文件名规则）

## 禁止

- **任何业务概念**（`Task`、`Session`、`Artifact`）——出现就是放错了地方，该去 `ai`
- **有状态**：模块级可变变量、单例、缓存
- **副作用**：写文件、发网络、开窗口
- 依赖 `core` / `data` / `ai` / `services` 任何一个包

## 和「工具函数放各包内部」怎么取舍

- 只被一个包用 → **留在那个包内部**，不往 `utils` 提
- 被两个以上包用，且与业务无关 → 提到这里

## 现状

已有 `paths.ts`：`isSafeRelativePath`（拦截绝对路径、盘符路径、`..` 穿越、空路径）与 `normalizeRelativePath`（统一分隔符、去掉开头 `./`）。被 `ai/tools/builtin` 与 `ai/domain/workspace` 共用。
