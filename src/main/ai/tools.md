# ai/tools

**职责**：工具协议与注册表。定义统一的 `Tool` 接口（名称、参数 schema、副作用等级、超时、是否需要授权），并管理可用工具集合。

**约定**：

- 外部工具优先走 **MCP**，内部工具实现同一接口；
- 每个工具必须声明**副作用等级**（只读 / 写本地 / 花钱 / 对外发送）——规划阶段据此要求用户确认；
- 工具调用必须可审计（谁、何时、参数摘要、结果状态）。

**允许依赖**：仅类型层面——引用包内 `domain.md` 的类型，用 `zod` 定义参数 schema。

**禁止**：

- 禁止 import `electron` / `react`；
- 禁止工具内部做权限判断（权限归 `policy`）。
