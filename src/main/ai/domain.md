# ai/domain

**职责**：领域模型与用例。会话、任务、产物、用户意图的核心类型与纯逻辑运算。

**允许依赖**：同包内的 `tools.md` 与 `providers.md` 定义的类型与接口。跨包只允许依赖 `utils`。

**禁止**：

- 禁止 import `electron`、`react`、任何 DOM / Node 平台 API；
- 禁止直接读写文件、数据库、网络——一律走注入的接口；
- 禁止出现 `if (isEnterprise)` 之类的版本判断。

**判据**：换掉外壳（桌面 → 服务端）时，这个包应当原样可用。

**现状**：空壳。依据 [ADR 0002](../../docs/adr/0002-技术栈选型与双版本架构.md)。
