# src/main/i18n

**职责**：多语言资源与解析。主进程与渲染进程共用同一套文案键。

## 为什么独立成包

Cherry Studio 的 `i18n/` 是它顶层集合里唯一一次「有意破例」——理由是主进程和渲染进程各自需要一套语言目录，但又必须共用同一份译文。拆在两边会导致同一句话说两遍、翻两次、漏一边。

## 内容

- 语言资源文件（`zh-CN` / `en-US`）
- `t()` 解析器与插值
- 键名规范与缺失检测

## 铁律

1. **键名是契约**：改键名等于破坏兼容，必须全量替换；
2. **两种语言必须同时更新**，不允许只加中文；
3. **组件里禁止硬编码用户可见文案**，一律走 i18n；
4. 业务包只使用 `t()`，不直接读语言资源文件。

## 禁止

- `react` / `electron`（`t()` 是纯函数，渲染层自己包 hook）；
- 在语言资源里放业务逻辑或动态拼接的句子（用插值，不要拼字符串）。
